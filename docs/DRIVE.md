# Drive（仮）— 設計メモ

ベンチの街・描画をそのまま使い、ゲームパッドで自由に走る別アプリ（`dev.zat.citydrive`）。
ガチのレースではなく「夜の街を流して楽しむ」手触りを目標にしている。

## 構成

| 場所 | 中身 |
| --- | --- |
| `drive/core` | 車両（`vehicle`）、街の当たり判定（`collision`）、追従カメラ（`chase_camera`）、自動運転（`autopilot`）、走行音（`audio_synth`）、ゲームループ（`drive_app`） |
| `drive/linux` | `citydrive`：SDL のゲームパッド／キーボード、`--headless --demo N --shots DIR --wav FILE` |
| `drive/tests` | 車の運動・当たり判定・音の単体テスト（19件） |
| `android/drive` | Android アプリ（Compose の画面、ゲームパッド入力、AAudio、C++ の描画スレッド） |
| `core/src/render/world.*` | ベンチと共有。任意の視点（`ViewPose`）、自車とヘッドライト（`PlayerCarState`）を追加 |

ベンチの計測コード（`BenchApp`）には手を入れていない。描画の共有部分を変えた時は、ベンチの固定ショットで差が出ないことを確かめる
（ヘッドライト対応の霧の変更で PSNR 49.5dB）。

## 車の手触り

240Hz の固定ステップ、描画は前後のステップを補間。

- **ハンドル**：最大舵角は速度で絞る（0.60 rad / (1 + 0.085 v)）。ヨーレートは自転車モデルで、横 G が μg（μ=1.05）を
  越える分は頭打ち＝アンダーステア。
- **ドリフト**：サイドブレーキ（6 m/s 以上）で「進行方向を車体の向きに追従させない割合」を 0.82 に上げ、ヨーの効きを 1.7 倍。
  離せば横滑りは 10/s で減衰して戻る。
- **前後**：出力 150kW・最大駆動力 7200N・空気抵抗・転がり抵抗・坂。0-100 km/h は約 5 秒、最高速は 230 km/h 前後。
  止まってブレーキを踏み続けると後退（最大 11 m/s）。
- **変速**：6速の自動。変速点はアクセル開度で変わる（流す時は 2600rpm で上げ、踏めば 6600rpm まで引っ張る）。
- **衝突**：車体を 3 つの円で覆い、押し出し＋撃力（反発 0.12、交通車 0.3、摩擦、回転）。
- **見た目**：加速で尻が沈み、減速で頭が下がり、旋回で外へ傾く（ばね・ダンパ）。

## 当たり判定

- 街区の台（高さ 0.15m）は縁石が壁になり、歩道・ビルには入れない
- 高架は「今の高さが床の近くなら床の上」。地上の車にとってはランプの下で天井が 1.6m 未満の区間が壁、高い所は下をくぐれる
- 橋脚・路上の小物・街の外周、交通車（カプセル）
- 人は段差のある歩道だけを歩かせる（路地は車道と同じ高さで、人が車の行く手をふさぐため）

## カメラ

ばね・ダンパの追従（速いほど硬く）。速度で画角 62→74°、ドリフト中は車体と進行方向の間を見る、右スティックで見回し、
建物・高架にはめり込まない（レイで手前に寄せる）。Y でボンネット視点。被写界深度は切る（前の道がぼけると走りにくい）。

## 音（ファイルなし、手続き合成）

エンジン（6気筒の爆発周波数と倍音、周期ごとの揺らぎ、アクセルで明るく）、吸気、風（速度の2乗）、雨、タイヤのスキール
（1.3kHz 前後の帯域ノイズ）、衝突のドン。Android は AAudio（低遅延）、Linux は SDL。

## 既知の制限（次にやること）

- 前輪が切れない・タイヤが回らない（車輪が車体のメッシュに焼き込み）
- 交通車は時刻で決まる経路を走るだけで、自車に反応しない。車線の端で瞬間移動する
- 交通は大通りと高架だけ。他の通りは空いている
- 画質は起動時に選ぶ（走行中の切り替えなし）
